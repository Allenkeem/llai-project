### 2. 연구 범위 · 선행연구 차용 여부 ★필수
- 본 분석은 26-1 빅데이터컴퓨팅 **기말 프로젝트로 직접 수행**
- **선행연구(타인) 차용: 없음** — LLAI 설계·수집·정제·분석·시각화 코드 전부 자체 개발
- **본인 이전 연구 차용: 없음** — 주제·방법론 골격은 본 과목 제안서에서 직접 설계 → 기말에 구현
- 외부 차용은 '공개 raw data + 경계 파일'뿐, 모두 출처 명시
  - KOSIS·사법연감·법률구조공단·대한변협 공공데이터
  - 시도경계 GeoJSON(southkorea-maps), 2009 변호사 분포(법률저널 2010 인용)
- → 데이터는 차용, **수집·정제·지수개발·분석·해석은 100% 본 프로젝트 수행**

### 3. 문제 제기 (Why)
- 로스쿨 이후 변호사 4만 명 시대, 그러나 자원은 어디에?
- 연구 질문: 어느 지역이, 얼마나 소외되는가?

### 4. 접근 방법 — LLAI
- 3개 차원(A1 변호사·A2 사건부담·A3 취약계층)을 하나의 지수로
- `LLAI = w₁·A1n + w₂·(1−A2n) + w₃·A3n`, 가중치 3종 병기

### 5. 데이터 5종과 난관
- 출처 5종 / 난관: 지역 단위 불일치(→두 단위), 다운로드 불가(→스크랩·우회)
- 검증: 법원관내 인구 = KOSIS 인구 일치

### 6. 데이터 수집 · raw data 정제 방법 ★필수
- **수집**: 변협 웹 스크래핑(HTML 표 파싱) / KOSIS·공단·사법연감 엑셀·CSV 다운로드
- **정제(raw→tidy)**:
  - 인코딩 자동판별, 가로형→세로형 변환, 다중헤더 파싱
  - 시도명 표준화(옛/신 명칭), 지역단위 매핑(14지방회·법원관내·도단위 → 13권역/10도단위)
  - 공단 반기→연 합산, 사법연감 본안사건 추출(비송 제외)
  - 결측·이상치 처리 → 권역×연도 패널 → 합계 교차검증
- 코드: `src/collect`, `src/prepare`
